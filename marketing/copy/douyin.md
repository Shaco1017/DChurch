# 抖音发布文案

## 口播脚本（约 25 秒，语速适中）

手机里的日程软件越装越多，广告、会员、云同步，一个比一个复杂。

后来我干脆自己写了一个，叫 DChurch。

打开就是日程和待办，数据只存在本机，不注册、不登录、没有广告。

重复的事设一次规则，未来一年的安排自动排好；做完自动进归档箱，想恢复随时找回。

浅色深色都做了，晚上看不刺眼；手机和网页都能用，代码还开源。

GitHub 搜 Shaco1017，安装包自取，完全免费。
