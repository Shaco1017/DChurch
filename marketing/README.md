## 截图说明

- 7 张浅色主题截图是 H5 版在默认状态下的真实界面（应用首次打开为浅色主题）。深色主题切换后日历月视图已采集 1 张样例（`calendar-month-dark.jpg`）。后续可在应用设置页切换深色主题后，重新采集整套深色主题截图覆盖即可。
- 所有截图均在页面静止、无 toast / picker / 弹层时采集，无多余操作痕迹。
- 截图不含浏览器地址栏，仅保留应用内容区 + 原生 tabBar，便于横向拼接成"功能组图"发布。

## 视觉一致性校验

- 封面、启动图、图标三者共用同一 SVG 路径（教堂 + 十字），比例完全一致
- 背景色值统一：`#22272A → #181B1D → #0F1113` 径向渐变（中心偏上，让下方文案区稍亮）
- 主体标记色值统一：`#E6EADF → #C3CDC0` 玻璃渐变 + 10% 透明度同色光晕
- 无水印、无外部素材依赖，可自由裁剪或二次编辑
