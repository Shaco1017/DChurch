## 项目简介

DChurch 是我个人利用业余时间写的一个日程 / 待办应用，名字取自“每天去教堂”的那点仪式感——给每天要做的事留一个安静的位置。

它没有云端、没有账号、没有推送运营，所有数据只存在你自己的设备里。你可以把它当成一个不会催你、不会分析你、也不会把你的计划卖给谁的备忘录。

- **纯本地**：数据保存在设备本地存储，不上传服务器，不需要注册登录
- **完全免费**：无广告、无内购、无会员、无付费墙
- **多端可用**：基于 UniApp + Vue 3 开发，可运行在 H5、微信小程序、iOS / Android
- **开源可改**：源码公开，欢迎自己改着玩

> 本项目为非盈利性质的个人开发日常工具，没有任何商业变现目的，所有功能完全免费开放。

## 功能说明

### 日程

- 周视图与月视图切换，按日期查看当天安排
- 点击日期快速新建事项，支持设置日期、起止时间、优先级与分类
- 日历上以圆点标记有安排的日子，一眼看清节奏

### 待办

- 按状态筛选，勾选即完成
- 支持优先级、截止日期、分类标签
- 已完成事项可一键归档，也可随时从归档箱恢复

### 重复规则

- 支持每日、每周（选星期几）、每月（选几号）、自定义间隔（每 N 天 / 周 / 月）
- 设置起止日期后批量生成所有可预期的实例
- 修改规则可重新生成实例；删除时可以选择保留或清理已生成的未完成事项

### 分类与整理

- 自定义分类名称与颜色，给事项打上归属
- 删除分类不会删除事项，相关事项会变成“未分类”

### 提醒

- 支持准时提醒、提前若干分钟 / 小时 / 天提醒（依赖系统本地通知能力）

### 数据备份

- 支持导出 / 导入备份文件，JSON 与 XML 两种格式可互相迁移
- 换设备、清缓存前建议先导出一份，安心一点

### 外观主题

- 浅色 / 深色 / 跟随系统三种模式，在「我的 → 外观主题」里切换
- 全局配色、组件、图标（含 tabBar 图标）同步适配，切换带过渡动画

## 安装说明

### 普通用户：直接拿走用

1. 打开仓库的 **Releases** 页面，下载对应平台的安装包（如 `.apk`；iOS 需要自签或自行用 Xcode 打包）
2. 安装后打开即可使用，**无需付费、无需注册账号、没有广告**
3. 如果暂时没有你需要的平台安装包，可以按下面的方式自行构建，几分钟就能跑起来

> 自取即用，不用打招呼，也不用付费。唯一的请求是：重要数据记得自己备份。

### 微信小程序

```bash
npm install
npm run build:mp-weixin
```

然后用微信开发者工具导入 `dist/build/mp-weixin` 目录即可预览。

### 网页版（H5）

```bash
npm install
npm run dev:h5      # 本地开发，默认 http://localhost:5173
npm run build:h5    # 产出静态文件到 dist/build/h5
```

把 `dist/build/h5` 丢到任意静态托管（GitHub Pages、Nginx 等）就能用。

### iOS / Android 安装包

项目已按 UniApp 规范配置好 `manifest.json` 中的应用图标（iOS 全尺寸 + Android 各密度）与启动页资源，使用 HBuilderX 打开项目后走「发行 → 原生 App 云打包 / 本地打包」即可生成安装包。

环境要求：Node.js 18 及以上、npm。

### 项目结构（简要）

```
src/
├─ pages/        # 日程、待办、我的、分类、归档、备份、重复规则
├─ components/   # 日历、任务行、任务面板等
├─ services/     # 存储、备份、提醒、主题、重复规则生成
├─ store/        # 全局状态与选择器
├─ static/       # 图标、启动图、tabBar 图标
└─ utils/        # 日期、常量、UI 辅助
```
